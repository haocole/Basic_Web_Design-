# A LANG HAO - Personal Portfolio

Welcome to my personal portfolio website.

This project is a personal portfolio that I am building to introduce myself,
showcase my skills, share my learning journey, and document my progress
in Web Development.

This portfolio website is being developed as part of my journey to become
a Full-stack Developer.

The website currently includes:

- Social media links
- Skills section

- Responsive layout

I am developing this project step by step and will continue improving it
as I learn new technologies and build more projects.
